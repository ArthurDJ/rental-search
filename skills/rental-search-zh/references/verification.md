# 核实

交付的每套房源，都要在汇报当天打开看过。这份文件讲怎么判断房源还在不在、怎么合并重复、怎么发现矛盾和诈骗，以及别人整理的名单怎么处理。

## 是否还挂着

打开房源自己的页面；搜索卡片可能比广告本身活得久。房源没了的迹象：

| 迹象 | 例子 |
|---|---|
| 已下架横幅 | Kijiji 的 "No Longer Available"；liv.rent 的 "marked as rented" |
| 没有价格，只有通知按钮 | Zumper 显示 "Monthly rent –" 和 "Notify me" |
| 404 或 "Page Not Found" | 先检查链接格式（`references/sites.md` → Craigslist） |
| 房东自己改了标题 | 标题里写 "RENTED" |

页面正文写"现可入住"、状态却显示已租出的，算已下架。在已下架名单里写明证据，比如"liv.rent 显示已租出，2026-11-06"。

也要记下和上次核对相比的变化：降价或涨价、新的入住日期、重新挂出。

## 重复房源

同一套房经常挂在好几个网站上，价格有时不一样；有时房东和想转租的租客会各发一条。

- 迹象：同一个地址或门牌号、同样的照片、同样的面积和价格、同样少见的措辞。
- 合并成一行，保留所有链接，写上目前最低的价格和对应的网站。价格不一样时要说出来。
- 同一栋楼里的两套不同的房，是两行。
- 怀疑是同一套但确认不了时，两条都留着，加一条备注（"可能和……是同一套"）。

## 矛盾

相信一条房源之前，先拿它和它自己对照。

- **楼盘标签和单元信息。** 楼盘页标着"Furnished"，同一栋楼在别的网站上的信息却写着"Furnished: No"，算**待核实**。
- **勾选框和正文。** 勾了"furnished"，正文却一个字没提家具；或者一处写"含车位"，另一处写"车位每月 $100"。
- **状态和正文。** 状态是"已租出"，正文写"立即可入住"：按已下架处理。
- **过期的日期。** 写着 "Available November 1"，而现在已经是那个月的月底，或者用户要下个月才入住：要问这个日期还算不算数；房子可能已经租出去了，也可能房东愿意等。
- **入住人数。** 写着"最适合单人"或"只租一个人"，而要住两个人：说得很死的算**不符合**，说得比较松的算**待核实**。

## 诈骗迹象

单独出现一条，在正常广告里也很常见。两条或以上同时出现，特别是前三条，就把这条广告列为疑似诈骗、写明原因，不要放进推荐。

1. 价格远低于同楼或同区域的类似房源（比如不到附近同面积要价的 60%）。
2. 发帖人马上要求离开平台联系（"去我主页找联系方式""只用邮件联系"），或者平台标注发帖人身份未验证。
3. 看房前就要钱：交定金"保留"房子、申请费，或者要求电汇、礼品卡、加密货币付款。
4. 房东"人在国外"，说会把钥匙寄过来。
5. 照片看起来像酒店、样板间或别的房源；文字和照片对不上。
6. 施压："很多人在问，今天就要定"。

不要为了验证怀疑去联系发帖人。把你看到的告诉用户，让用户自己决定。

## 别人给的名单

交接文档、之前会话的表格、别的 agent 的短名单，或者用户自己的表格，都只是线索。

- 继承过来之前，每套房源都重新打开看。
- 能核对的说法都核对：通勤（实测）、地址（在页面上找）、"水电全包"（读原文）。
- 名单上有说法被证明是错的，就在"更正"里直接写出来，方便用户更新其他依赖这个说法的地方。
